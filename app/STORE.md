# Публікація додатку XFit у Google Play та App Store

Додаток — нативна оболонка (Capacitor 8) навколо «Моєї карти», таймера та «Моїх тренувань» з сайту.
Усе потрібне вже в цій папці:

| Що | Де |
|---|---|
| Проєкт Android | `app/android/` (пакет `ua.com.xfit.app`, версія 1.0.0) |
| Проєкт iOS | `app/ios/` (тільки iPhone, портретна орієнтація) |
| Збірка вебчастини | `app/scripts/build-www.mjs` → `npm run build` |
| Іконки й заставка (джерела) | `app/assets/` |
| Автоматичні збірки | `.github/workflows/app-android.yml`, `.github/workflows/app-ios.yml` |
| Тексти, скриншоти, банер | `app/store/` (`listing-uk.md`, `forms-uk.md`, `screens/`) |
| Політика конфіденційності | https://xfit.com.ua/privacy.html |

Нативні функції (важливо для перевірки Apple): максимальна яскравість у режимі сканування карти, екран не гасне під час таймера, вібровідгук, системне «Поділитися», камера для штрихкоду, кнопка «Назад» на Android.

## Крок 0. Підготовка (один раз)

**0.1. Основний сайт.** Додаток працює з https://xfit.com.ua (карта, реєстрація, посилання «Запроси друга»). Версія з бети вже перенесена на основний сайт.

**0.2. База даних Supabase.** Мають бути виконані `supabase-update-growth.sql` і `supabase-update-delete.sql` (видалення карти — обовʼязкова вимога обох магазинів). Перевірка: у додатку «Моя карта» → «Видалити мою карту» видаляє карту без повідомлення «Видалення ще не налаштоване».

**0.3. Тестовий акаунт для перевірки магазинами.** В адмінці → «Новий клієнт»:
- Імʼя: `App Review`
- Телефон: `+380990000001`
- Абонемент: будь-який, «Діє до» — через рік
- Дата народження: `01.01.2000`

Вхід у додатку: «Увійти» → «🎂 Дата народження» → цей телефон і дату. Не видаляй цього клієнта, поки додаток у магазинах.

## Крок 2. Android — ключ підпису (один раз)

Google Play підписує додаток своїм ключем, а ти підписуєш кожне завантаження **ключем завантаження (upload key)**.

1. Встанови Java (наприклад, разом з Android Studio) і в PowerShell виконай:
   ```powershell
   keytool -genkeypair -v -keystore xfit-upload.jks -alias xfit -keyalg RSA -keysize 2048 -validity 10000
   ```
   Придумай пароль (запиши!), на питання про імʼя можна відповісти «XFit».
2. **Збережи `xfit-upload.jks` і пароль у надійному місці** (менеджер паролів + копія на флешці). Без них оновлення не завантажиш (відновити можна лише через підтримку Google).
3. Перетвори ключ на текст для GitHub:
   ```powershell
   [Convert]::ToBase64String([IO.File]::ReadAllBytes("xfit-upload.jks")) | Set-Clipboard
   ```
4. GitHub → репозиторій **XFit** → Settings → Secrets and variables → Actions → **New repository secret** — додай 4 секрети:

   | Назва | Значення |
   |---|---|
   | `ANDROID_KEYSTORE_BASE64` | вставити з буфера (крок 3) |
   | `ANDROID_KEYSTORE_PASSWORD` | пароль сховища |
   | `ANDROID_KEY_ALIAS` | `xfit` |
   | `ANDROID_KEY_PASSWORD` | пароль ключа (зазвичай той самий) |

> Ключ і паролі ніколи не потрапляють у репозиторій — `app/.gitignore` їх відсікає.

## Крок 3. Android — збірка

GitHub → **Actions** → «Додаток Android» → **Run workflow** (гілка `main`). Через ~5 хвилин унизу сторінки запуску зʼявиться артефакт `xfit-android-N` → завантаж і розпакуй `app-release.aab`.

*Альтернатива на своєму компʼютері:* встанови Node.js 22 і Android Studio, потім у папці `app`: `npm ci`, `npm run android` → Android Studio → Build → Generate Signed Bundle.

## Крок 4. Google Play Console

1. **Створити додаток:** назва `XFit — карта клієнта`, мова українська, тип «Додаток», безкоштовний.
2. **Налаштування додатку** (розділ «Панель» → завдання по черзі) — відповіді в `store/forms-uk.md`:
   - Політика конфіденційності → `https://xfit.com.ua/privacy.html`
   - Доступ до додатку → тестовий акаунт з кроку 0.3
   - Реклама → немає
   - Вікова категорія → анкета IARC
   - Цільова аудиторія → 18+
   - Безпека даних → таблиця з `forms-uk.md`; посилання на видалення акаунта `https://xfit.com.ua/privacy.html#delete`
   - Додатки для здоровʼя → «Активність і фітнес»
3. **Основна сторінка в магазині:** тексти з `store/listing-uk.md`, іконка `icon-googleplay-512.png`, банер `feature-graphic-1024x500.png`, скриншоти з `screens/googleplay-phone/`. Категорія — «Здоровʼя та фітнес», контактна пошта — робоча пошта XFit.
4. **Тестування → Внутрішнє тестування** → створити випуск → завантажити `app-release.aab` → погодитися на «Підписання додатків Google Play» → додати свою пошту в тестувальники → перевірити на своєму телефоні.
5. **Закрите тестування** (для особистого акаунта — 12 тестувальників, 14 днів): створи список з поштами (адміністратори, тренери, постійні клієнти), надішли їм посилання на участь.
6. **Робоча версія (Production)** → країни: Україна → створити випуск з тим самим `.aab` → «Надіслати на перевірку». Перевірка — від кількох годин до 7 днів.

## Крок 5. iOS — підготовка (один раз)

Збірка для iPhone відбувається на Mac-сервері GitHub — власний Mac не потрібен.

1. https://developer.apple.com/account → **Certificates, Identifiers & Profiles → Identifiers → +** → App IDs → App → Description `XFit`, Bundle ID **Explicit** `ua.com.xfit.app` → Continue → Register.
2. https://appstoreconnect.apple.com → **Мої додатки → + → Новий додаток**: платформа iOS, назва `XFit — карта клієнта`, мова Українська, Bundle ID `ua.com.xfit.app`, SKU `xfit-app`.
3. App Store Connect → **Користувачі та доступ → Інтеграції → App Store Connect API → Ключі команди → +**: назва `GitHub`, доступ **Admin** (потрібен, щоб автоматично створювати сертифікати). Завантаж файл `AuthKey_XXXXXXXX.p8` (**тільки один раз!**), запиши **Key ID** і **Issuer ID** (вгорі сторінки).
4. **Team ID**: developer.apple.com → Membership details.
5. GitHub → Settings → Secrets and variables → Actions — додай секрети:

   | Назва | Значення |
   |---|---|
   | `APPLE_TEAM_ID` | Team ID (10 символів) |
   | `APPSTORE_API_KEY_ID` | Key ID |
   | `APPSTORE_API_ISSUER_ID` | Issuer ID |
   | `APPSTORE_API_KEY_P8` | увесь текст файлу `.p8` (відкрий у Блокноті, скопіюй разом з рядками BEGIN/END) |

## Крок 6. iOS — збірка й TestFlight

GitHub → **Actions** → «Додаток iOS» → **Run workflow**. Через ~15 хвилин збірка зʼявиться в App Store Connect → TestFlight (ще 10–30 хв обробки). Встанови TestFlight на iPhone, додай себе у «Внутрішнє тестування» і перевір додаток.

> Якщо запуск iOS завершився помилкою підпису — перевір, що ключ API має доступ **Admin**, Bundle ID зареєстровано (крок 5.1), а угоди в App Store Connect → «Бізнес» прийнято. Текст помилки надішли мені — виправлю.

## Крок 7. App Store — сторінка й відправка на перевірку

App Store Connect → додаток → версія 1.0.0:
- **Знімки екрана iPhone 6.9"** → 5 файлів з `screens/appstore-6.9in/`
- **Рекламний текст, Опис, Ключові слова, Підзаголовок** → `store/listing-uk.md`
- **URL підтримки** `https://xfit.com.ua/`, **URL політики** `https://xfit.com.ua/privacy.html`
- **Збірка** → обрати збірку з TestFlight
- **Інформація для перевірки** → вхід потрібен: телефон `+380990000001`, «пароль» — дата народження `01.01.2000`; примітки — текст з `forms-uk.md`
- **Конфіденційність додатку**, **Віковий рейтинг**, **Ціна (безкоштовно)**, **Доступність (Україна)** → `forms-uk.md`
- **Додати на перевірку** → перевірка зазвичай 1–3 дні.

## Оновлення додатку

- **Тексти, ціни, оголошення, абонементи** — оновлюються одразу з адмінки, нова збірка не потрібна (дані беруться з бази).
- **Зміни дизайну чи функцій «Моєї карти» / таймера** — потрібна нова збірка: збільш `versionName` у `app/android/app/build.gradle` і `MARKETING_VERSION` в `app/ios/App/App.xcodeproj/project.pbxproj` (напр. 1.0.1), запусти обидва workflow, завантаж нові збірки в Google Play та App Store Connect. Номер збірки збільшується автоматично.

## Що варто додати пізніше

- **Відкриття посилань карти одразу в додатку** (App Links / Universal Links) — потрібні відбитки ключа з Google Play і Team ID; зробимо після першої публікації.
- **Push-сповіщення** («абонемент закінчується через 3 дні») — потрібен Firebase.
